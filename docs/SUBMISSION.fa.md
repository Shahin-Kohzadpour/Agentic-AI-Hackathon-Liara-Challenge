# بستهٔ تحویل

## محتوای بسته

فایل‌ها در `submission/` قرار دارند:

| فایل | توضیح |
| --- | --- |
| `DEMO.fa.mp4` | ارائهٔ فارسی حدود پنج دقیقه، صدای مصنوعی، تصاویر اجرای واقعی؛ اجرای پیوسته نیست |
| `LIVE-RUN.silent.mp4` | ضبط خام حدود دو دقیقه از انتشار و بررسی دوباره، بدون صدا |
| `negahban-source.zip` | سورس، آزمون‌ها، راه‌اندازی و مستندات |
| `negahban-submission.zip` | سورس + ویدئوها + شواهد |
| `evidence/` | پیشنهاد اصلاح، آزمون‌های مستقل، گزارش نهایی، نتیجهٔ MCP و بررسی مرورگر |

بسته‌ها با `python3 scripts/package-submission.py` از فهرست مجاز ساخته می‌شوند و شامل `.env`، دیتابیس، کلیدهای session، snapshotهای خصوصی یا `node_modules` نیستند. اسکریپت نبود مقادیر کلیدهای محلی شناخته‌شده را بررسی می‌کند.

## ادعای اصلی برای داور

درخواست تجاری خطای ۵۰۰ دارد در حالی که health check سالم است. Codex اصلاح واقعی تابع را تولید می‌کند، یازده آزمون مستقل (هفت اصلی و چهار مرزی) آن را می‌سنجند، MCP بدون تأیید امکان انتشار ندارد، مالک diff را تأیید می‌کند و همان snapshot روی لیارا منتشر می‌شود. موفقیت فقط با بررسی قرارداد پاسخ روی release منتشرشده ثبت می‌شود. اولین probe ناموفق و بررسی دوبارهٔ موفق در شواهد حفظ شده‌اند.

این نسخه برای نمونهٔ ثبت‌شدهٔ Node.js است. اتصال به مخزن دلخواه، رفع عمومی خطاها و پایش دائمی پیاده‌سازی نشده‌اند. [README](../README.md) و [گزارش اعتبارسنجی](VALIDATION.fa.md) مرجع دامنهٔ واقعی هستند.

## وضعیت فعلی

- ۳۱ آزمون backend، build و browser-check با Codex واقعی، MCP واقعی و `test:live` با کنسول واقعی لیارا موفق شده‌اند.
- رابط کاربری در ۲۳ اکتبر ۲۰۲۶ بازطراحی شده است: فضای کار چت‌محور، کارت تأیید درون گفتگو، چیدمان موبایل ثابت. تصاویر `docs/images/` همین وضعیت را نشان می‌دهند.
- ویدئوی فارسی پیش از افزودن چهار آزمون مرزی ضبط شده است؛ عدد «هفت آزمون» در آن، اجرای تاریخی را نشان می‌دهد و در [DEMO.fa.md](DEMO.fa.md) هم همین‌طور توضیح داده شده است.
- گزارش‌های `AUDIT` و `VALIDATION` وضعیت همان تاریخ را ثبت می‌کنند و بازنویسی نشده‌اند.

## پیش از ارسال نهایی

1. ویدئوی فارسی را یک‌بار تا انتها ببینید و تلفظ‌ها و تصاویر را بررسی کنید.
2. دسترسی داوران به مخزن را بررسی کنید. اگر مخزن خصوصی است، یا دسترسی داده شود یا بستهٔ ZIP تنها مرجع باشد.
3. برای دمو زنده، `npm run dev` و در ترمینال دیگر `npm run access` را اجرا کنید؛ کلید خصوصی نباید در تصویر بیاید.
4. نمونهٔ ابری در پایان اجرای واقعی روشن مانده است؛ نرخ تأییدشده هنگام ایجاد حدود ۱۰۴۲ تومان در ساعت بود. خاموش‌کردن یا حذف بعد از داوری با تصمیم مالک انجام می‌شود.
5. عدد Uptime، MTTR یا صرفه‌جویی اندازه‌گیری‌نشده اعلام نکنید.

## وضعیت نمونهٔ ابری

برنامهٔ واقعی در `https://negahban-demo-4d0934.liara.run` مستقر است؛ `/healthz` سلامت پایه و `/api/summary` قرارداد تجاری را ارائه می‌کند. مسیر `/` صفحهٔ فروشگاه کامل ندارد. داشبورد کنترل عمداً روی ماشین توسعه و فقط loopback اجرا می‌شود.

اگر نمونه دوباره به نسخهٔ معیوب بازنشانی شده باشد، این وضعیت عمدی و قابل‌بازتولید است؛ برای نمایش بازیابی، از داشبورد درخواست بررسی بسازید و کارت تأیید را بپذیرید.
