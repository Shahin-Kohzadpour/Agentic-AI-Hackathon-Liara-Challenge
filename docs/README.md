## قاعدهٔ نوشتن

- هر عدد (تعداد آزمون، release، قیمت) باید به یک فایل شاهد یا خروجی اجرا وصل باشد.
- محدودیت‌ها کنار ادعا نوشته می‌شوند، نه در پانویس.
- گزارش‌های تاریخی (`VALIDATION`، `AUDIT`) بازنویسی نمی‌شوند؛ تغییر وضعیت در سند تازه ثبت می‌شود.
